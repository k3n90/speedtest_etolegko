# Замер скорости скачивания

Скрипт десять раз подряд скачивает ответ по указанному адресу и печатает среднее время запроса, общий объём данных и скорость.

## Требования

Python 3.9 или новее. Сторонние пакеты не нужны.

## Запуск

```text
python speedtest.py <url>
```

Пример:

```text
python speedtest.py "https://test.com/"
```

Без адреса скрипт печатает справку и завершается с ненулевым кодом.

## Что измеряется

Десять GET-запросов идут строго последовательно: следующий начинается только после того, как предыдущее тело ответа прочитано целиком. Потоки и асинхронные запросы не используются.

Время одного запроса — от начала открытия соединения до конца чтения тела. В него входят DNS, установка соединения, TLS, ожидание заголовков и скачивание тела. Редиректы проходятся автоматически, в объём попадает итоговое тело.

Объём — число реально прочитанных байт.

Таймаут одного запроса — 30 секунд.

## Единицы

| Величина | Единица | Как считается |
|---|---|---|
| Среднее время | миллисекунды (мс), 1 знак после запятой | сумма длительностей / 10 × 1000 |
| Объём | байты и мегабайты (МБ) | 1 МБ = 1000² байт |
| Скорость | мегабайты в секунду (МБ/с), 2 знака | суммарные байты / 1000² / суммарные секунды всех 10 запросов |

Скорость считается по суммарному времени серии, а не по среднему времени одного запроса.

Пустое тело ответа ошибкой не считается: объём и скорость будут равны нулю.

## Ошибки

Если любой из десяти запросов не удался (некорректный адрес, сеть, DNS, таймаут, HTTP-ошибка), скрипт пишет сообщение в stderr, завершается с кодом 1 и не печатает среднее время, объём и скорость. В зачёт идёт только полная серия из десяти ответов.
